# 抖音聊天气泡制作

先读 [references/制作规范.md](references/制作规范.md)，区分官方要求、设计参考、本任务经验和未经证实的平台实现。规则更新时回到所列官方页面核验。

## 按文字区设计

1. 确认本次上传的确切文件、原始素材、静态/动态类型及用户的保留要求。检查尺寸、alpha、正文底板实际高度，区分“猫咪更小”和“整图更小”。用户要求保留原像素时，按授权拆层、等比缩放和重排；需要重绘时使用宿主图像工具，并说明方法。保持像素和保持风格是不同承诺。
2. 先规划固定 51 px 正文、参考 72×72 px 保护区及内部留白。以约 120 px 实体高度为设计起点，再安排装饰；198×162 是资源上限。细横幅常需重建文字底板，裁透明边不能增加内部高度。
3. 将猫脸、月牙、珠链和星星放在固定角落；让伸缩带穿过平整背景及连续边框。颗粒纹理伸缩后可能变成条纹，以长句、多行预览发现，再降低该区纹理对比或重构该区。
4. 分别指定四条切线与文字框。九格不是固定等分；报错的三分位置采样不等于切线。坐标用源图像素，并声明右下边界是否包含。
5. 导出透明 PNG 和配置 JSON，运行下方工具。检查短字、长句、多行、深浅背景中的正文、装饰和接缝，修复后再导出。
6. 在获授权的编辑器上传，分别拖动切线和文字框，设置文字色值，运行平台预览。没有平台访问或上传权限时交付本地结果、坐标和预览，明确平台验证待完成。发布/提交审核按用户授权处理。

## 可执行预检

依赖 Python 3、Pillow。动态 WEBP 需额外逐帧检查，本工具处理静态 PNG。

```bash
python scripts/bubble_check.py assets/example.json --out ./checks --font /path/to/chinese-font.ttc
```

将示例 JSON 换为当前配置，图片路径相对 JSON 所在目录。`--font` 可选，提供本机中文字体才生成含字预览；字体仅用于本地模拟，平台实际字体与行高以平台为准。

脚本检查尺寸、文件大小、alpha、正文区实色/对比度、声明的内部留白；按截图规则保守扫描外侧空隙；模拟点九并验证四角像素保持。退出码 0 表示本地硬检查通过，不代表平台切图或审核通过；warnings 仍需逐项阅读。

配置字段：

- `source_size` 为 `[宽,高]`；`cuts` 包含 `left/top/right/bottom`。
- `text_box` 为 `[左,上,右,下]`，右下不包含；`protected_box` 为其内部保护区。
- `font_size` 为当前官方默认 51。
- `artworks` 每项包含 `id/file/text_color`，可覆盖 `text_box`；`panel_box` 描述气泡底板主体，排除外伸装饰；`border_width` 为描边宽度。
- 随包示例坐标只服务于示例，不是所有气泡的固定模板。

## 交付判断

交付当前 PNG、文字色值、点九/文本框坐标、深浅色长短文本预览和预检结果，保存到用户指定项目。分别报告“格式通过”“本地预览完成”“平台预览通过”。只测透明外接框或向空白添不可见像素，不能证明阅读与伸缩适配。

尺寸报错查文件；外伸报错查主体/装饰布局和真实 alpha；压字查正文区/底板；变形查切线；条纹查伸缩区纹理；本地与平台数值不符先核对文件名。当前上传文件放在明确目录，预览/示意图单独标注。
