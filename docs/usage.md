# 使用流程

## 1. 准备素材

保留原始高清文件，另建当前交付目录。先确定要求：保留原像素、保留角色与风格，或允许重新设计。原像素保留通常涉及拆层和重排；重生成不能保证猫脸、姿态、线条与原图一致。

核对真正上传的文件名。高清原图、旧版、预览图与上传 PNG 分开存放，避免用旧文件测试新配置。

读取[完整规范](../douyin-chat-bubble/references/制作规范.md)，标注底板实体、正文区、装饰、伸缩带和外部透明空间。检查实际底板高度；一张图在 198×162 范围内，不意味着能装下固定字号正文。

## 2. 安装或直接使用 Skill

下载 [Skill ZIP](../dist/douyin-chat-bubble-skill.zip)，将 `douyin-chat-bubble` 文件夹复制到目标 Agent 的技能目录。Codex 默认常用 `~/.codex/skills/`；如果使用自定义配置目录，按实际配置安装。

不希望安装时，克隆仓库后告诉 Agent：

```text
先读取当前仓库 douyin-chat-bubble/SKILL.md，再按其中流程完成我的气泡制作。
```

已安装后：

```text
使用 $douyin-chat-bubble：附件是原图和上传报错。
保留猫咪造型，给正文安排可读底板；交付透明 PNG、配置和深浅色拉伸预览。
保存到我的项目目录，不自动发布。
```

若 Agent 未发现技能，重新加载其技能列表或开启新会话，并确认 `SKILL.md` 位于技能文件夹顶层，而不是重复嵌套两层目录。

## 3. 制作文字底板与装饰

1. 按 51 px 正文、参考保护区及规定内部留白安排底板。
2. 结合设计需要调整角色大小和位置，使其与正文、伸缩带分离。
3. 将需要保持形状的图案放入固定角落。切线穿过连续边框与平整背景。
4. 对纸纹或颗粒做长句、多行预览。单向拉长会把密集纹理变成条纹，需弱化或重构伸缩区域。
5. 导出满足尺寸、整除和文件大小限制的透明 PNG。

所用绘图/图像工具由 Agent 能力、用户保留要求和执行环境决定。本仓库的 Python 工具负责检查与预览，不自动生成或重新排版任意原图。

## 4. 为自己的素材创建配置

复制 `douyin-chat-bubble/assets/example.json` 到自己的任务目录，修改 `artworks[].file` 和其他坐标。图片路径相对于 JSON 所在目录，不依赖本仓库固定磁盘路径。

每张图明确：源尺寸、左/上/右/下切线、文字框、保护区、正文色、底板实体范围和描边宽度。字段解释与最小示例见[配置说明](./manifest.md)。

源坐标右/下不包含；例如 `[37,54,155,126]` 表示 118×72 px。文字框不是伸缩区，两组坐标分别设置。

## 5. 本地预检与预览

在仓库根目录运行：

```bash
python -m pip install -r requirements.txt
python douyin-chat-bubble/scripts/bubble_check.py /path/to/config.json --out checks
```

提供中文字体则同时生成含字预览：

```powershell
python douyin-chat-bubble/scripts/bubble_check.py douyin-chat-bubble/assets/example.json --out checks --font C:/Windows/Fonts/msyh.ttc
```

检查 `preflight.json` 中的每项 `errors` 和 `warnings`。硬检查失败时退出码为 1；格式、对比度、留白等硬检查通过时为 0。透明扫描失败目前作为 warning 提示，因为它不是完整的平台实现。

查看预览：

- 短字：正文居中、没有压装饰或越出色块。
- 长句：猫脸、月牙、尖角尺寸保持，边线与纹理没有异常接缝。
- 多行：上下留白合理，底板能随行数增长，角色不会竖向拉长。
- 深浅背景：正文清楚，边缘/装饰的实际观感可接受。

脚本自动验证四角像素保持，但这不能证明用户把全部装饰正确放在固定区域；仍需人工查看。示例字体和行高是本地模拟，平台结果为最终依据。

## 6. 在抖音编辑器配置

打开[抖音聊天气泡平台](https://effect.douyin.com/emoji)，在获授权账号下上传当前 PNG。

分别完成：

1. 按源坐标比例拖动四条点九分割线。
2. 单独拖动文本框，让正文落在设计的底板区域。
3. 设置正文颜色。
4. 点击效果预览，检查单字、短句、长句、多行及深浅模式。

网页会缩放资源，屏幕像素不等于源像素。蓝线示意图、预览图都不是上传素材。不要只替换 PNG 却沿用错误的旧切线和文字框。

平台预览确认后，再根据用户授权填写信息、提交审核或发布。没有真实看到平台结果时，将状态写成“本地验证完成，平台预览待确认”。

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| `ModuleNotFoundError: PIL` | 使用同一个 Python 执行 `python -m pip install -r requirements.txt` |
| `cannot open resource` | `--font` 路径无效；换成本机中文 TTF/TTC，或暂时移除字体参数只做检查 |
| 素材找不到 | `file` 相对于配置 JSON，不相对于执行命令的终端目录 |
| `Text box contains transparent pixels` | 文字框跨出实体底板，或该区 alpha 不足；修正底板/文字框 |
| 对比度失败 | 调整正文颜色、底板颜色或纹理；不要只看整图平均色 |
| `Target is smaller than its fixed edges` | 固定边过大，目标尺寸无法容纳；重规划切线或目标尺寸 |
| 文字预览放不下 | 文字框过小或切线配置不适合样例；按固定字号重新设计 |
| 平台间距仍报错 | 先确认上传文件名，再检查报错位置的实体/装饰与真实透明度 |

记录问题时附确切文件、配置、报错和实际平台截图，避免只报告“上传失败”。
